## Guards

- app/api/v1/routeScopeWiring.test.ts:1136 — "matches the unlisted baseline exactly" (and the it.each suites at :833, :1078) — guard test that globs `app/**/route.*`, imports every module, and reads sibling source files (`readFileSync`/`readdirSync`, metric `guard=true`) to enforce that every OAuth-guarded route is registered with the expected guard/scopes. Slowest file in the slice (5.9s total, 4.3s single test). Not enforceable by oxlint/TypeScript: it checks runtime `__guard`/`__scopes` handler tags, which a linter cannot see. Deliberate architectural guard — keep, but the runtime glob+import makes it the suite's biggest fixed cost; a build-time codegen of the EXPECTED table would remove the runtime cost.
